# Branding

Copied from the NazmulCodes website logo (https://www.nazmulcodes.org/favicon.svg) so the
auth app, Google's consent screen and the main site all show the same mark.

| File | Use |
|---|---|
| `google-oauth-logo-120.png` | Upload in Google Auth Platform → Branding → App logo (120×120 PNG). |
| `logo-512.png` | Larger PNG for other listings. |
| `logo.svg` | Source. `public/brand-mark.svg` and `public/favicon.svg` are copies of it. |

If the logo on nazmulcodes.org changes, replace `logo.svg`, regenerate the PNGs and favicons,
and re-submit brand verification in Google (changing the logo needs a new review).
